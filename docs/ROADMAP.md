各フェーズは「目的 → ゴール（完了条件） → 作業 → 既知の問題・残りの作業」の順に書く。ゴールは、元の指示書の完了条件に、本プロジェクトで追加した検証条件（TDD・CI など）を加えたもの。フェーズを完了とするのは、ゴールの全項目が ✅ になったときだけとする。

- **目的**: なぜその段階を行うのか、誰にどんな価値を提供するのか。
- **ゴール（完了条件）**: 終了時に何ができ、どのテスト・成果物・実測結果で達成を確認するのか。
- **作業**: ゴールを達成するための実装・調査・検証。作業に着手しただけでは完了としない。

**Phase 0〜7は全体の開発段階、M0〜M6は直近の実行単位、R0はM1前に追加した比較試作**を表す。両者の番号は対応しない。たとえば M3 は Phase 4 の先行検証、M4 は Phase 3 のデータ生成、M6 は Phase 4 の学習に対応する。どちらにも目的とゴールを記載し、実装する順番は後半の「実行計画」に従う。

## 全体の目的

9×9×9（729マス・372枚）の三次元将棋を題材に、ルールエンジン・ブラウザゲーム・合成データセット・Transformer モデル・自己対局と分散学習を一貫して公開し、**誰でも再現できる三次元将棋 AI 研究プラットフォーム**を作る（`docs/PROJECT_SPEC.md`）。

**主用途はAI vs AIを見て・眺める観戦であり、そのためのモデル開発と研究を行う。** ゲームの面白さ、状況の分かりやすさ、見映え、モデル比較の再現性を評価する。人間対AIは補助機能とし、人間同士の対局・マルチプレイは扱わない（2026-10-26 ユーザー指定）。

## 横断的なゴール（全フェーズ共通）

- すべての実装を TDD で行う。期待値はルール文からの手計算か独立した参照実装で用意し、変異テストで検出力を確認する（ADR-003）。
- GitHub Actions（Public リポジトリの標準ランナー）で、main の push / PR ごとにテストを自動実行する。M0 で PR と必須 CI による main 保護を整備済み。
- 重要な決定は ADR（`docs/ARCHITECTURE_DECISIONS.md`）と本ファイルに記録する。
- 費用が発生する操作は、見積もりを示してユーザーの承認を得てから行う。
- 実装・文書変更の前に必ず作業ブランチを作り、PR と必須 CI を経由する。main への直接 push、force push、削除、保護の bypass は行わない（`CONTRIBUTING.md`）。
- 人間同士の対局・マルチプレイは後続フェーズでも実装しない。対局は人間 vs AI と AI vs AI 観戦に限定する。
- Python は3.14系を基本とし、依存が未対応の場合のみ3.13系を使う。現在は `.python-version` に3.14.9を固定している。

## Phase 4: Transformer-S — 学習未着手（先行検証M3は完了）

**目的**: 盤面を入力に Policy と Value を出す小型 Transformer（5–10M パラメータ）で、「学習 → 評価 → ONNX 変換 → ブラウザ推論 → 対局 UI への組み込み」の一連の流れを最初に通す。本格的な GPU 投資の前に、ブラウザで動くことを確かめる。

**ゴール（完了条件）**

| 条件 | 検証方法 |
|---|---|
| 学習できる | Phase 3 のデータで損失が下がる（小規模からVast.ai／CloudRift。利用承認後） |
| 評価できる | Policy Top-1/Top-k 正解率、交差エントロピー、Value 損失、合法手選択率、Random AI と Search AI に対する勝率 |
| チェックポイントから再開できる | 同じ実行環境・固定seedで、中断再開と継続実行のモデル・optimizer・RNG・学習stepを照合するテスト。数値の一致基準はbackendごとに事前に定義 |
| 変換済みモデルが実機の Web で推論できる | 同じ精度形式の基準実装と対応する ORT Web backend の出力を、形式ごとに決めた許容誤差で比較する。対象実機・ブラウザで推論時間、メモリ、初回ロード時間を計測 |
| 量子化・低精度化した版も実際に試せる | Web 向けに作成・評価した実行可能な変換版（FP16・INT8等）を、採用版・比較版ともデモで選択し、対応実機で対局・観戦できる。精度が下がった版も含む。配布ファイルの SHA-256 と評価対象が一致し、各版の精度・棋力・速度・サイズの差を記録する |
| Web 上のAI vs AI観戦に組み込める | 両AIのモデルと各変換版を選び、合法手だけで対局を進められる。停止・1手送り・速度変更と、モデル・条件・結果の記録を公開E2Eで確認。人間対AIも補助機能として検証 |
