# M6の変換モデル比較と初回HF公開

2026-10-29 UTC。[再学習・HF再開状態の復旧](M6_RETRY.md)後、初期／学習済みTorchとFP32／FP16／INT8重み版の固定評価を完了した。全モデルでtest3,589件・Random40局・M1探索20局、合計300局。**実モデルのブラウザ計測と公開catalogへの登録は未完了で、M6全体の完了記録ではない。** [固定集計・モデルdescriptor・元report hash](experiments/m6-converted-models.json)。

## 同条件の精度・対局

| モデル | Policy Top-1 | Top-5 | Value MSE | M1探索20局：勝／敗／引分／打切り |
|---|---:|---:|---:|---|
| 初期Torch | 1.950% | 9.947% | 0.230918 | 0／0／18／2 |
| 学習済みTorch | 75.592% | 96.573% | 0.0337401 | 0／3／9／8 |
| FP32 ONNX | 75.592% | 96.573% | 0.0337401 | 0／3／9／8 |
| FP16 ONNX | 75.592% | 96.573% | 0.0337415 | 0／2／9／9 |
| INT8重み版ONNX | 75.536% | 96.573% | 0.0336749 | 0／4／9／7 |

Random40局は全モデルで0勝0敗0引分・40打切り。最大256手、同じ8手の序盤・先後入替・固定seedと探索予算を使い、打切りを引分や敗北へ変えていない。開幕seedを単位とするpaired bootstrap95%の観測勝率区間は全て[0, 0]だが、打切りを含む限定指標であり、無制限対局の勝率を保証しない。FP16の敗数が少ないことも、打切り増加と小標本を無視した棋力改善の根拠にはしない。

INT8のPolicy Top-1はFP32より3,589件中2件分低い。マスク後の合法手選択率は全モデル100%。マスク前は学習済み各版で約0.167%で、合法手マスクは必須。教師模倣精度の向上は確認できたが、この対局評価で棋力改善は確認できていない。

## 変換した実ファイル

| 形式 | Bytes | SHA-256 |
|---|---:|---|
| FP32 | 20,452,346 | `1e8281d10d99c8bd87d7eeffc500def7af7ebd60fb1b4ffe6415b43f3bd76890` |
| FP16 | 10,411,041 | `e8827283e8629983b7f25af5c89afc972904e99014ee0fa5cf2b84573214002d` |
| INT8重み版 | 5,458,790 | `6eb6b5bcbdbebef4d22a9d152d99cbc9a888b73ded81ad52b8260235e4ac5d3b` |

[学習済み数値契約](M6_MAIN.md#fp32変換の失敗と次の基準)の全要素照合にFP32の4固定入力が成功した。旧基準での失敗は[初回記録](M6_MAIN.md)へ保持する。FP16／INT8は同形式の参照出力を生成し、FP32との差も全4入力で別集計した。固定入力のPolicy最大絶対差はFP16で最大0.02799、INT8で最大0.56276。4入力のraw argmaxが同じだったことだけで、精度低下なしとは判断しない。

INT8は重みのper-tensor対称量子化で、活性・計算はFP32。容量低下をそのまま高速化や実行メモリ低下とは呼ばない。上のtest・対局は各形式の同じ実ONNXをORT CPUで実行した結果であり、ブラウザ性能やGPU対応の証拠とは区別する。

## 初回のHF推論パッケージ

[voxelshogi/voxelshogi-transformer-sの固定revision](https://huggingface.co/voxelshogi/voxelshogi-transformer-s/tree/94278f11df547863b1f98283b4b19a4a5ff88998)にApache-2.0で公開した。public/manual・Community OFF、37ファイル全てのbytes／SHA-256を外部Linuxで再取得・照合済み。Model Cardには学習／データの来歴・CC-BY-4.0帰属、5モデルの結果と制約、全3形式のbytes／hash・数値差、取得条件を記載した。

この初回Cardのブラウザ性能は未測定と明記している。次は同じ重みhashの実機候補計測を行い、結果をCardへ追記した固定revisionを最終catalogへ登録する。HFの取得ゲートを迂回するCloudflareへの重み複製は行わない。Macに保存したのは小さいmetadataだけで、モデル／datasetは外部Linux内で扱った。
