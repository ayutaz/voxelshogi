# 承認モックからの本番実装の進捗

2026-11-14。対象は[U2〜U6](ARENA_IMPLEMENTATION_PLAN.md)。研究・GPU・追加学習・X投稿は再開しない。

| 段階 | 実装したもの | 残る確認 |
|---|---|---|
| U2 | 盤中心の画面、9層の案内、元／先の別表示、設定シート、3D失敗時の2D入口 | Linuxで3サイズの実画像・寸法・盤位置・focus |
| U3 | 観戦操作、人間先後／相手の開始導線、取消保持、明示分岐、終局と履歴の区別、全棋譜保存 | 実Worker4経路、既存モデル、カメラ回帰 |
| U4 API | [PR #186](https://github.com/ayutaz/voxelshogi/pull/186)。後方互換schema 2、原子的更新、容量／回数上限 | 正常mergeと新API配信後の実HTTP／D1照合 |
| U4 client | 初手、30秒の変更集約、停止／終局／置換、固定本文の自動再送。送信UIを撤去しprivacy更新 | Linux E2Eと本番D1。import・履歴・分岐の除外を含む |
| U5 | 新UIのE2E・画像の保存経路を更新 | Claude Codeの実装後再レビュー、必須／関連CI、通常公開と配信照合 |
| U6 | 新画面の収録操作、中央の実異層着手の選択、冒頭の拡大と層字幕、公開SHA照合をハーネスへ追加 | Linuxで冒頭3秒、15秒本編・2案・ポスターの再制作／実画像と全検査 |

Macの軽量確認は関連10ファイル84テスト、typecheck、関連lintが成功。
APIの4変異とUI／自動保存の8変異を検出して復元した。全変異・WebGL・探索・実モデル・録画はLinuxへ置く。
これらのローカル結果を公開済み・実ブラウザの成功とは扱わない。

専用D1 `voxelshogi-games`へ0002 migrationを先行適用済み。追加table／triggerだけで旧tableは保持した。
現時点で自動保存clientは公開していない。実対局の収集を検証済みとは記載しない。
後続の[保存仕様](../AUTOMATIC_GAME_STORAGE.md)と[旧方式の記録](../GAME_DATA_COLLECTION.md)を区別する。

次はLinuxの候補版検証→画像とソースのClaude Code再レビュー→通常mergeと公開確認→動画更新。
CI取得は最短10分間隔とし、待機中は独立した実装・文書・動画準備を進める。
