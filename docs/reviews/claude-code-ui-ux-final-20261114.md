## 2. P1（公開前の修正を推奨）

### P1-A 観戦中、盤が1手ごとに上下へずれる
- **原因**：「思考を中断」ボタンは、`phase === 'thinking'`のときだけ表示されます（`App.tsx:352`）。表示されるのは観戦操作パネルの中で、盤のすぐ上です。
  - 観戦中、コントローラーは手ごとに状態を切り替えます。待ち時間に`waiting`（`arena-controller.ts:181`）、探索中に`thinking`（`arena-controller.ts:151`）です。
  - このためボタンが1手ごとに現れたり消えたりし、その下の持ち駒・盤・追従設定が約35pxずつ上下に動きます。
- **再現**：PCで初期設定のまま「観戦を開始」を押します。初期のAIはNormal・約1秒です（`App.tsx:37,44`）。思考中の約1秒は盤が下がり、待ち時間の400msは盤が上がる、という動きが毎手くり返されるはずです。Easyでは一瞬のちらつきになります。
- **根拠の範囲**：ソースからは確定しています。ただし今回の画像はどれも一時停止中なので、実画面ではまだ観測していません。
- **影響**：中心となる用途「眺める」と層追従の見やすさを、毎手損ないます。
- **最小修正**：ボタンを常に表示し、「1手指す」と同じ`.row`の中へ置きます。止められるときだけ動作させます。
  ```tsx
  <button type="button" data-testid="cancel-search" aria-disabled={aiStatus.phase !== 'thinking'}
    onClick={() => { if (aiStatus.phase === 'thinking') pause(); }}>思考を中断</button>
  ```
  N1と同じ`aria-disabled`方式なので、focusも失いません。E2Eでは「実行中の2手の間で、盤の`getBoundingClientRect().top`が変わらない」ことを確認するのが簡単です。

## 4. 観点ごとの所見
- **用途**：「9層の将棋を、AIが指す。」と「研究用Alpha」、勝利条件、モデル不要の説明が、3サイズとも最初の画面にあります。誇張した表現はありません。
- **観戦の開始**：開始ボタンは主要ボタン（primary）で幅150px、盤より上にあります。画像は2手目以降の一時停止中なので、ボタンは「再開」と表示されています。
- **停止／1手送り／取消**：N1・N5は対応済みです。新規・モード切替・読み込みでは置き換え前の確認があります（`App.tsx:128`）。
- **任意送信**：既定はOFFで、案内リンク・30日の保持・OFFにしたときの破棄が、画面とprivacy.htmlで一致しています。
- **動画**：字幕は大きく高コントラストで、UIとの被りはありません。1.5秒の時点で異層への着手（軌跡と着地）が見えます。最後のフレームのURLと「研究用Alpha」も読めます。
- **OGP**：見出し・副題・「研究用Alpha」は小さいサムネイルでも読めます。説明文は盤の外に置かれています。
